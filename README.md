## 🚀 GitHub Actions से APK कैसे बनाएं (How to Build APK on GitHub)

1. इस पूरे एक्सपोर्ट किए गए फोल्डर को अपने GitHub Repository में अपलोड या **push** करें।
2. अपने GitHub Repository के **Actions** टैब पर जाएं।
3. **"Build Android APK"** वर्कफ़्लो अपने आप चलना शुरू हो जाएगा।
4. 2 मिनट के अंदर जब वर्कफ़्लो पूरा हो जाए, तो उसके नीचे **Artifacts** सेक्शन से **`app-debug.apk`** डाउनलोड करें और अपने Android मोबाइल में इनस्टॉल करें!

## 💻 Local Build (Computer / Android Studio)

### Prerequisites
- Node.js 18+
- JDK 17
- Android Studio (SDK Platform 34)

### Commands
```bash
# 1. Dependencies install karein
npm install

# 2. Android platform sync karein
npx @capacitor/cli sync android

# 3. Debug APK build karein
cd android
./gradlew assembleDebug
```

Generated APK location: `android/app/build/outputs/apk/debug/app-debug.apk`
